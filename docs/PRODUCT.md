# Prism 产品文档

> 版本：v0.1（草案，待确认）  
> 定位：多租户 SaaS 多模态 Agent 平台 — 对话驱动内容生产、多模态知识库、社媒矩阵发布、付费广告投放。

---

## 1. 产品一句话

**Prism** 让营销与内容团队用自然语言完成「品牌知识检索 → 图片/视频生成 → 社媒发布 → 付费投放」，并在同一套多租户云端系统中管理素材、知识与投放效果。

---

## 2. 目标用户与场景

| 角色 | 核心诉求 |
|------|----------|
| 品牌 / 电商运营 | 快速出图出片、对齐品牌调性、多平台分发 |
| 投放 / 增长 | 创意变体批量产出、对接巨量/Meta、看效果闭环 |
| 内容主理人 | 品牌素材与规范沉淀成知识库，图搜图、片段复用 |
| 租户管理员 | 成员权限、配额、模型与渠道密钥隔离 |

**典型场景**

1. 「用我们上季主视觉风格，生成 3 张小红书封面 + 一条 15 秒种草视频」  
2. 「这张商品图在知识库里有没有相似历史素材？」  
3. 「把成片发到抖音/小红书，并同步创建 Meta 广告组草稿」  
4. 「找出知识库里这段产品演示视频 00:12–00:28 的片段，做成新广告素材」

## 3. 范围分层（必须先对齐）

### 3.1 MVP（本期先做，文档确认后可进页面设计）

| 能力 | 说明 | 验收标准 |
|------|------|----------|
| 多租户基础 | 租户隔离、成员、角色、登录 | 租户 A 看不到租户 B 数据 |
| 对话 Agent | 自然语言驱动生图 / 生视频 | 对话内出结果、可再改一轮 |
| 简单知识库 | 上传文档 / 图片；文本问答 + **图搜图** | 上传后可检索；以图搜相似图 |
| 资产库 | 生成结果、上传素材统一归档 | 可预览、下载、打标签 |
| 管理后台（薄） | API Key / 模型供应商配置（租户级） | 租户自配密钥，不串租 |

**MVP 明确不做**

- 视频片段检索（放入 Phase 2，但架构预留）
- 社媒矩阵真实发布
- 巨量 / Meta 真实投放 API
- 复杂工作流画布、短剧全链路、计费中台完整版

### 3.2 Phase 2 — 多模态检索增强 + 分发

| 能力 | 说明 |
|------|------|
| 视频片段检索 | 上传视频 → 抽帧/切段 → 语义+视觉检索到片段级 |
| 社媒矩阵发布 | 抖音 / 小红书 / 视频号 / B 站等账号绑定与定时发布 |
| 发布日历与任务 | 定时、失败重试、发布状态回写资产 |

### 3.3 Phase 3 — 付费投放闭环

| 能力 | 说明 |
|------|------|
| 巨量引擎投放 | 广告账户授权、计划/单元草稿、素材上传、基础报表拉取 |
| Meta Ads 投放 | 同上（Campaign / Ad Set / Ad 草稿与素材） |
| 创意 ↔ 投放映射 | 成片/图片一键推送到投放草稿；效果数据回写资产 |

> 产品原则：社媒发布与付费投放都是正式目标；实现上分阶段，避免 MVP 同时打穿两端导致无法上线。

## 4. 核心用户旅程（MVP）

```
登录租户 → 打开「创作对话」
  → （可选）引用知识库 / 上传参考图
  → 下达生成意图（图 / 视频）
  → Agent 规划提示词并调用生成
  → 结果进入资产库
  → 继续对话迭代（改风格 / 尺寸 / 时长）
  → （可选）「在知识库里找相似图」对比历史素材
```

Phase 2+ 延伸：资产 → 发布任务 / 投放草稿 → 效果数据回流。

## 5. 功能模块（产品视角）

### 5.1 创作对话（Agent Studio）

**形态：对话式 Agent（带工具的 LLM），不是「只会生图的流水线」。**

| 用户输入类型 | 系统行为 |
|--------------|----------|
| 普通问答（如「我们主色是什么？」） | **直接返回文本答案**；若挂了知识库则先检索再答（RAG） |
| 创作意图（如「生成一张春季海报」） | 调用生图/生视频工具，气泡里出结果卡片 |
| 混合（如「按规范说明主色，并出一张 KV」） | 先文本说明，再调工具出图 |

- 多轮对话；支持附件（参考图、品牌 PDF）
- 工具能力（MVP）：文生图、图生图、文生视频、图生视频、知识库文本检索、图搜图
- 展示：文本流式输出 + 生成进度、失败原因、结果卡片（进资产库）
- 会话可命名、可归档；归属当前租户与工作空间

### 5.2 多模态知识库

| 阶段 | 能力 |
|------|------|
| MVP | 文档入库（PDF/MD/DOCX）、图片入库、文本问答、**图搜图** |
| Phase 2 | **视频片段检索**、片段预览裁剪、片段入库为可复用素材 |

产品规则：

- 知识库按租户隔离；可建多个库（如「品牌规范」「历史投放素材」）
- 检索结果需带来源（文件名、页码/时间戳、缩略图）
- 生成时可「引用知识库」作为风格/文案约束（简单 RAG，非重型 GraphRAG）

### 5.3 资产中心

- 类型：图片、视频、文档衍生素材、发布/投放衍生记录（后期）
- 操作：预览、下载、标签、文件夹/集合、相似推荐（复用图搜）
- 血缘（简版）：由哪次对话、哪次生成任务产出

### 5.4 社媒矩阵（Phase 2）

- 账号 OAuth / 扫码绑定（按平台能力）
- 选择资产 → 适配文案/封面 → 定时或立即发布
- 多账号并行；状态：排队 / 成功 / 失败 / 需人工
- 风险提示：平台风控、违规词；产品侧做基础校验，不承诺「永不封号」

### 5.5 付费投放（Phase 3）

- 巨量、Meta 账户授权（租户级）
- 从资产创建「投放草稿」（计划结构可模板化）
- 拉取展示/点击/转化等基础指标；与创意资产关联
- MVP 不做：自动出价优化、跨账户智能分配（可作为后续智能体能力）

### 5.6 租户与权限（SaaS 必需，MVP 就要）

| 角色（建议） | 权限概要 |
|--------------|----------|
| Owner | 计费、销毁租户、全部配置 |
| Admin | 成员、知识库、渠道密钥、发布账号 |
| Creator | 对话生成、知识库读写、资产 |
| Analyst | 只读资产与投放报表（Phase 3） |
| Viewer | 只读 |

## 6. 非功能需求（产品侧）

| 项 | 要求 |
|----|------|
| 多租户 | 数据、对象存储前缀、向量索引、密钥全面隔离 |
| 可用性 | MVP 目标：核心创作链路可用；生成依赖上游模型 SLA |
| 安全 | 租户密钥加密存储；操作审计（谁生成了什么） |
| 合规 | 生成内容水印/声明可配置；广告素材合规提示 |
| 配额 | 按租户限制：存储、生成次数、坐席数（计费可后置，配额表先有） |

## 7. 成功指标（建议）

| 阶段 | 指标 |
|------|------|
| MVP | 周活跃创作者、对话→成功出图/出片率、图搜图 Top5 点击率 |
| Phase 2 | 发布成功率、每租户绑定账号数 |
| Phase 3 | 草稿创建数、素材→广告关联率、报表回写延迟 |

## 8. 页面信息架构（草案，文档确认后细化为线框）

> 仅列导航与页面清单，不在此阶段出视觉稿。

### 8.0 工作空间

- 登录后先进入 **工作空间列表 / 切换器**（一租户可多空间，如「春季大促」「品牌常青」）。
- 对话、知识库、资产均挂在当前工作空间下；设置里可管理空间成员（可复用租户角色或空间级角色，实现阶段再定）。

### 8.1 租户应用（选定工作空间后）

1. **工作台** — 当前空间概览：最近对话、最近资产、快捷入口  
2. **创作对话** — Agent 主界面  
3. **知识库** — 库列表 / 库详情（上传、检索、图搜）；片段检索入口 Phase 2 灰显预留  
4. **资产中心** — 素材浏览与管理  
5. **发布**（Phase 2）— 账号、任务、日历  
6. **投放**（Phase 3）— 账户、草稿、报表  
7. **设置** — 成员、角色、模型与密钥、配额与用量、工作空间管理  

### 8.2 平台超管（可选，后期）

- 租户列表、全局模型路由、系统健康

### 8.3 营销站（可选）

- 落地页 / 定价（与核心产品可分离仓库）
