# Prism 页面信息架构（MVP）

> 品牌：Prism · UI：中文 · 层级：租户 → 工作空间 → 业务页  
> 作者 / 开发者：**jintao**（[@jintao0693](https://github.com/jintao0693)）  
> 视觉草稿：`design/prism-ui/index.html`（浏览器打开预览）

---

## 导航结构

```
登录
 └─ 工作空间选择 / 创建
      └─ 应用壳（顶栏：空间切换 · 用户）
           ├─ 工作台
           ├─ 创作对话
           ├─ 知识库
           │    ├─ 库列表
           │    └─ 库详情（文档 / 图搜 · 片段检索灰显）
           ├─ 资产中心
           ├─ 发布（Phase 2 灰显）
           ├─ 投放（Phase 3 灰显）
           └─ 设置
                ├─ 工作空间
                ├─ 成员与角色
                ├─ 模型与密钥
                └─ 用量
```

---

## MVP 页面清单

| ID | 页面 | 主要区块 |
|----|------|----------|
| P0 | 工作空间选择 | 空间卡片列表、新建空间、最近进入 |
| P1 | 工作台 | 欢迎条、快捷创作、最近对话、最近资产 |
| P2 | 创作对话 | 会话列表、消息流、工具状态、输入区、结果卡片 |
| P3 | 知识库列表 | 库卡片、新建库、搜索 |
| P4 | 知识库详情 | 上传、文本检索、**以图搜图**、结果区；片段检索入口禁用+「即将推出」 |
| P5 | 资产中心 | 筛选（图/视频）、网格、预览抽屉 |
| P6 | 设置 | 侧栏分组 + 表单（骨架即可） |

---

## 设计方向（视觉）

- 意象：棱镜分光 — 清晰、克制，一条细光谱作为品牌信号，避免紫渐变与通用 SaaS 卡片墙。
- 基调：浅色工作室（冷雾白 + 墨色文字），主色深青石。
- 字体：展示用 Sora（品牌 Latin），正文 Noto Sans SC。
