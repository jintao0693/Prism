# Prism 产品与技术优化清单

> 维护者：jintao（[@jintao0693](https://github.com/jintao0693)）  
> 更新日期：2026-11-16  
> 适用范围：当前 MVP（对话 / 知识库 / 资产 / 任务中心 / 火山方舟）之后的下一阶段  
> 关联文档：[PRODUCT.md](PRODUCT.md) · [PROGRESS.md](PROGRESS.md) · [TECHNICAL.md](TECHNICAL.md) · [../ROADMAP.md](../ROADMAP.md)

本文回答两件事：**产品上还差什么体验与增长能力**，以及**技术上怎样把 MVP 撑到可上线、可协作、可扩展**。优先级按「对信任与闭环的伤害」排序，而不是按技术炫技度。

---

## 0. 当前基线（已具备，不再重复规划）

| 领域 | 已落地能力 |
|------|------------|
| 创作对话 | SSE 真流式、意图路由、文/图生图、文/图生视频、参考图、KB 勾选记忆、自动滚底、首条 brief 命名、失败保留草稿、整理会话、会话搜索/重命名/删除 |
| 媒体体验 | 缩略图、lightbox 预览/下载、改稿 `parentAssetId` 血缘展示、提示词编译（品牌/负面词） |
| 知识库 | 文档/图片入库、文本检索、以文搜图、以图搜图、补齐向量、「带回对话」 |
| 资产 / 任务 | 资产中心送回对话、本月用量实算、软配额提示、视频 job 落库 + 任务中心轮询 |
| 工程壳 | JWT + 工作空间隔离、方舟租户配置、Docker Compose 半成品、基础单测与 CI |

**明确结论：** 闭环「查规范 → 出图出片 → 归档 → 再改」已经可演示；下一刀应打在**可信赖的生产环境、可回放的长任务、可治理的素材与权限、以及 Phase 2 分发**上。

## 1. 产品优化（按优先级）

### P0 — 信任与生产可用性（不上线会踩雷）

| ID | 项 | 现状痛点 | 建议做法 | 验收标准 | 预估 |
|----|----|----------|----------|----------|------|
| P0-1 | **生产部署一键化** | 本地可跑，服务器侧 Docker/域名/HTTPS/环境变量未固化 | Compose `full` + Nginx/Caddy、`.env.prod` 模板、健康检查、备份脚本 | 一台云主机 30 分钟内可访问 HTTPS 控制台 | L |
| P0-2 | **密钥与密钥轮换** | 方舟 Key 已加密存库，缺轮换、审计、泄露应急 | 设置页「轮换 Key」、操作审计日志、禁止日志打印明文 | 轮换后旧 Key 失效且历史任务可读 | M |
| P0-3 | **配额可执行策略** | 仅软提示（图 50 / 视频 10），不拦截 | 租户级硬上限 + 接近阈值 UX + 超限明确错误码 | 超限返回 402/429 且 UI 可解释 | M |
| P0-4 | **长任务断线后的会话回写** | 视频 job 可完成资产，但断线时助手消息可能不落库 | job 成功后后台写 assistant Message，或任务中心「同步到会话」 | 关页再开，会话内能看到成片卡片 | M |
| P0-5 | **错误可行动** | 已有可读错误，缺「去设置 / 去任务中心 / 重试」深链 | 错误组件带 CTA | 鉴权失败一点进设置 | S |

### P1 — 创作闭环加深（直接提升留存）

| ID | 项 | 现状痛点 | 建议做法 | 验收标准 | 预估 |
|----|----|----------|----------|----------|------|
| P1-1 | **结果快捷再创作** | 用户需手动再说「再偏暖 / 做成预告」 | 结果卡：再改一版 / 做成预告 / 送回参考（此前刻意延后，现可做） | 一键带 `parentAssetId` 进入下一轮 | S |
| P1-2 | **多版本对比** | 改稿血缘有文案，无并排对比 | 资产/对话内 A/B 对比视图 | 可选两张图并排看差异 | M |
| P1-3 | **批量变体** | 一次只出一张 | 「同 prompt 出 2–4 张」+ 选优归档 | 单次请求多结果卡 | M |
| P1-4 | **品牌包 / Look 预设** | 提示词编译写死游戏品牌提示 | 工作空间级 Brand Pack（色板、禁忌、镜头气质）可编辑 | 改 Brand Pack 后新生成可感知 | M |
| P1-5 | **知识库治理** | 有检索，缺重命名/删除/版本/权限 | KB 与条目 CRUD、可见范围、过期归档 | 误传可删；条目有更新时间 | M |
| P1-6 | **会话级「项目」感** | 会话列表偏聊天工具 | 会话绑定活动标签、封面缩略图、导出 brief | 工作台一眼能认项目 | M |
| P1-7 | **协作评论** | 单人演示足够，团队无法在图上批注 | 资产评论 + @成员（只读先做） | 链接分享只读批注 | L |
| P1-8 | **模板市场** | 快捷 chips 偏硬编码 | 行业模板（电商主图 / 游戏 KV / 短视频钩子）可收藏 | 新租户 1 分钟出第一张合规图 | M |

### P2 — 增长与差异化（对齐 PRODUCT Phase 2/3）

| ID | 项 | 说明 | 预估 |
|----|----|------|------|
| P2-1 | 视频片段检索 | 抽帧 + 语义检索到片段级，服务剪辑与投放素材复用 | L |
| P2-2 | 社媒矩阵发布 | 抖音/小红书等绑定、定时、失败重试、状态回写资产 | L |
| P2-3 | 投放草稿推送 | 巨量 / Meta 草稿与素材映射、效果回写 | L |
| P2-4 | 多工作空间创建/迁移 | 入口仍偏演示 | M |
| P2-5 | 对外分享链接 | 单条成片/会话只读分享，便于评审 | M |
| P2-6 | 数据分析看板 | 本月生成量、热门 prompt、失败率、人均耗时 | M |

### 产品体验细节清单（可穿插在 P0/P1 迭代）

1. **相对时间**：侧栏/工作台用「今天 14:20」而非裸时间戳。  
2. **会话封面**：取最近一张生成图作 thumb，替代纯色块。  
3. **空态引导**：新空间引导「先建知识库 → 勾选 → 发第一句」。  
4. **无障碍**：lightbox Esc、焦点陷阱、对比度（失败态红字已有）。  
5. **移动端**：三栏对话在窄屏改为抽屉会话列表。  
6. **国际化预留**：文案键位化（非本期必做）。  
7. **「演示账号」水印策略**：正式租户隐藏 demo 文案。  
8. **成功反馈**：生图完成 toast + 侧栏用量即时刷新（已有部分 refresh）。

## 2. 技术优化（按优先级）

### T0 — 上线与数据正确性

| ID | 项 | 现状 | 建议 | 预估 |
|----|----|------|------|------|
| T0-1 | **Alembic 迁移** | `create_all` + `schema_migrate` 补列 | 正式 migration；禁生产裸 `create_all` | M |
| T0-2 | **Postgres + pgvector 默认生产** | SQLite 可开发，向量能力弱 | Compose 生产 profile 强制 PG；文档写清 | M |
| T0-3 | **对象存储** | 本地磁盘 / 半成品 S3 | MinIO/S3：公私链、生命周期、缩略图异步 | M |
| T0-4 | **配置与密钥** | `.env` 分散 | 12-factor：`SECRET_KEY`、DB、Redis、S3、方舟默认模型分环境 | S |
| T0-5 | **观测性** | 基本 logging | 结构化日志 + request_id + SSE/job 关联；可选 OpenTelemetry | M |
| T0-6 | **备份与恢复** | 无 | DB 定时备份 + 媒体桶版本；演练文档 | M |

### T1 — Agent / 媒体架构

| ID | 项 | 现状 | 建议 | 预估 |
|----|----|------|------|------|
| T1-1 | **真·队列 Worker** | 视频靠进程内 `asyncio`；重启丢任务 | Redis/RQ 或 ARQ：`generate_video` / `generate_image` / `ingest`；API 只投递 | L |
| T1-2 | **方舟任务与本地 job 对齐** | 已有 `external_task_id` 字段 | 断点续轮询、幂等落资产、webhook（若方舟支持） | M |
| T1-3 | **多步 tool / function-call** | 规则选工具，单轮单主工具 | 模型 function-calling：KB→改图→出片流水线 | L |
| T1-4 | **上下文策略产品化** | 自动压缩 + 手动整理 | 可视化 token 预算、可调 keep_recent、压缩预览 diff | M |
| T1-5 | **提示词编译可配置** | `prompt_compiler` 内置品牌句 | Brand Pack JSON + A/B 编译策略 | M |
| T1-6 | **生图参数面板** | 尺寸/比例藏在模型默认 | UI 暴露 ratio/size/seed（若模型支持） | M |
| T1-7 | **缩略图与视频海报** | 图有 thumb；真视频缺抽帧海报 | ffmpeg/云端截帧写入 `poster` | M |

### T2 — 质量、安全、性能

| ID | 项 | 建议 | 预估 |
|----|----|------|------|
| T2-1 | **测试加厚** | media gateway、tool 选择、video job、SSE 契约、前端关键交互 e2e（Playwright） | L |
| T2-2 | **安全** | 速率限制、上传 MIME/大小二次校验、SSRF 防护（拉取方舟 URL）、CSP | M |
| T2-3 | **权限模型** | owner/admin/creator/viewer 真正落到 API（资产/KB/会话） | M |
| T2-4 | **性能** | 消息分页、资产虚拟列表、SSE 心跳、embedding 批量 | M |
| T2-5 | **前端工程** | React Compiler 约定、大页 code-split、图片 `sizes`、错误边界 | S–M |
| T2-6 | **API 契约** | OpenAPI 生成 TS 类型，减少 `Record<string, unknown>` 手工 map | M |
| T2-7 | **多供应商抽象** | MediaProvider 已有 demo/volc；可加第二家并做 failover | L |

### T3 — 平台化（中长期）

| ID | 项 | 说明 |
|----|----|------|
| T3-1 | 多区域 / 多存储副本 | 合规与延迟 |
| T3-2 | 计费中台 | 按张/秒/seat；对接配额 T0/P0 |
| T3-3 | 插件与 Webhook | 资产就绪通知企业微信/飞书/钉钉 |
| T3-4 | 私有化交付包 | 离线 compose + 许可证 |

## 3. 建议落地节奏（8 周示意）

```text
Week 1–2  上线底座：T0-1~4、P0-1、P0-3、P0-5
Week 3–4  长任务可靠：T1-1、T1-2、P0-4；任务中心与会话双向同步
Week 5–6  创作加深：P1-1、P1-3、P1-4、T1-5、T1-7
Week 7–8  质量与协作：T2-1~3、P1-5、P1-6；评估是否启动 P2-1 视频片段 spike
```

**依赖你方输入的卡点**

1. 服务器连接方式与域名（部署工程）  
2. 生产 Postgres / 对象存储选型（云厂商）  
3. 方舟生产模型 ID 与配额预算  
4. Phase 2 是否坚持「视频片段优先」还是「社媒发布优先」

## 4. 决策原则（避免范围膨胀）

1. **先可信，后好看**：部署、配额、任务落库优先于视觉改版。  
2. **先闭环，后平台**：创作→归档→再改 做厚，再做发布/投放。  
3. **Agent 可解释**：每次工具调用、压缩、编译提示词要对用户可见或可追溯。  
4. **租户隔离不可破**：任何新 API 必须带租户/工作空间校验与测试。  
5. **演示数据不等于产品承诺**：UI 只暴露已实现能力（已纠偏，需持续守住）。
